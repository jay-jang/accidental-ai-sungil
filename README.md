# 어쩌다 AI — 성일 정보고 편

성일정보고등학교 IT 동아리 특강(50분 × 2교시)용 인터랙티브 강의 자료입니다.
슬라이드를 넘기는 방식이 아니라, **한 장의 커다란 모눈종이 캔버스** 위를 카메라가 확대·이동하며 진행합니다(프레지 방식).

## 여는 법

**온라인:** https://jay-jang.github.io/accidental-ai-sungil/ — 브라우저로 바로 열립니다. 특정 장은 주소 뒤에 `#프레임id`를 붙이면 됩니다 (예: `#network`).

**로컬:** `index.html`을 크롬 또는 엣지에서 더블클릭해 엽니다. 빌드나 설치는 필요 없습니다.
손글씨 글꼴(나눔손글씨 펜)은 `assets/fonts`에 함께 들어 있어 인터넷이 없어도 같은 모양으로 보입니다. 제목·본문 글꼴은 Google Fonts에서 받으며, 인터넷이 없으면 비슷한 기본 글꼴(맑은 고딕·바탕 등)로 바뀌어도 글이 넘치지 않도록 맞춰 두었습니다. 사진은 모두 `assets/img`에 들어 있습니다.

## 발표 단축키

| 키 | 동작 |
|---|---|
| → · Space · PageDown | 다음 (단계가 있는 장은 한 단계씩) |
| ← · PageUp | 이전 |
| O · Esc | 전체 지도 보기 / 돌아가기 |
| G | 목차 (원하는 장으로 바로 이동) |
| 마우스 휠 · 드래그 | 자유롭게 확대·이동 (→를 누르면 경로로 복귀) |
| 다른 프레임 클릭 | 그 장으로 바로 이동 |
| 숫자 + Enter | 해당 번호의 장으로 이동 |
| N | 발표자 노트 (말할 내용·실습 방법·학생 질문) |
| P | 발표자 창 (듀얼 모니터용, 팝업 허용 필요) |
| F | 전체 화면 |
| T | 밝은/어두운 테마 (교실 프로젝터는 밝은 테마 권장) |
| B | 화면 가리기 |
| M | 미니맵 고정 |
| S | 압축 모드: ‘보충’ 표시된 장 건너뛰기 |
| 마우스를 화면 아래로 | 진행 막대 · `‹ ›` 버튼 · 타이머 · 지도/목차/노트 버튼이 나타남 (데모를 만지는 동안에는 숨어 있어 출처 줄을 가리지 않음) |
| 하단 타이머 클릭 | 교시별 타이머 시작/정지 (더블클릭 초기화). 계획 시간보다 3분 이상 늦으면 빨간색 |

클리커(프레젠터 리모컨)는 PageUp/PageDown을 보내므로 그대로 쓸 수 있습니다.

## 휴대폰·태블릿에서 보기

키보드가 없어도 됩니다. 터치 기기에서는 화면 아래에 막대가 나타납니다.

| 동작 | 하는 일 |
|---|---|
| `‹ 이전` · `다음 ›` 버튼 | 한 장씩 (단계가 있는 장은 한 단계씩) |
| 옆으로 밀기 | 왼쪽으로 밀면 다음, 오른쪽으로 밀면 이전 |
| `목차` | 95장 목록에서 원하는 장으로 바로. 테마·압축 모드·노트·사용법도 여기에 |
| `지도` | 전체 지도에서 가고 싶은 장을 탭 |
| 두 손가락 벌리기 | 확대한 뒤 한 손가락으로 끌어서 읽기 (`다음`을 누르면 원래 경로로) |
| 두 번 탭 | 그 자리를 크게 보기 · 다시 두 번 탭하면 원래 크기로 |

세로 화면에서는 현재 장 바깥이 흐리게 가려집니다. 가로로 돌리면 글자가 더 크게 보입니다. 데스크톱에서도 마우스를 화면 아래로 가져가면 나타나는 `‹ ›` 버튼, `목차` 버튼(G 키)으로 마우스만으로 넘길 수 있습니다.

## 분량과 시간

- 총 95장: 실제 프레임 92장 + 지도·마무리용 화면 3장. 모든 장에 발표자 노트(말할 내용, 클릭할 곳, 학생 질문)가 있습니다.
- 1교시 42장 · 계획 48분 (S 압축 모드 약 45분)
- 2교시 53장 · 계획 49분 (S 압축 모드 약 43분)
- ‘보충’으로 표시된 장은 압축 모드에서 자동으로 건너뜁니다. 지도(O)에서는 언제든 클릭해 열 수 있습니다.

## 구성

- **1교시 (왼쪽 고리)**: 오프닝 → 어쩌다 엔지니어(강사 소개) → AI, 대체 뭐야?(개념 + 실습) → 생각하는 기계를 꿈꾼 70년(1943–2016)
- **2교시 (오른쪽 고리)**: ChatGPT는 어떻게 말할까 → 폭발(2017–2026) → 사람과 회사, 그리고 긴장 → 돈은 어디로 흐르나 → AI 시대의 일 → 마무리(제목 프레임 안으로 돌아옴)
