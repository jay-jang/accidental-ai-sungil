# 어쩌다 AI — 성일 정보고 편

성일정보고등학교 IT 동아리 특강(50분 × 2교시)용 인터랙티브 강의 자료입니다.
슬라이드를 넘기는 방식이 아니라, **한 장의 커다란 모눈종이 캔버스** 위를 카메라가 확대·이동하며 진행합니다(프레지 방식).

## 여는 법

`index.html`을 크롬 또는 엣지에서 더블클릭해 엽니다. 빌드나 설치는 필요 없습니다.
글꼴은 Google Fonts에서 받으므로 인터넷이 연결되어 있으면 가장 보기 좋습니다. 인터넷 없이도 기본 글꼴로 동작합니다. 사진은 모두 `assets/img`에 들어 있습니다.

## 발표 단축키

| 키 | 동작 |
|---|---|
| → · Space · PageDown | 다음 (단계가 있는 장은 한 단계씩) |
| ← · PageUp | 이전 |
| O · Esc | 전체 지도 보기 / 돌아가기 |
| 마우스 휠 · 드래그 | 자유롭게 확대·이동 (→를 누르면 경로로 복귀) |
| 다른 프레임 클릭 | 그 장으로 바로 이동 |
| 숫자 + Enter | 해당 번호의 장으로 이동 |
| N | 발표자 노트 (말할 내용·실습 방법·학생 질문) |
| P | 발표자 창 (듀얼 모니터용, 팝업 허용 필요) |
| F | 전체 화면 |
| T | 밝은/어두운 테마 (교실 프로젝터는 밝은 테마 권장) |
| B | 화면 가리기 |
| M | 미니맵 고정 |
| S | 압축 모드: ‘보충’ 표시된 장 건너뛰기 |
| 하단 타이머 클릭 | 교시별 타이머 시작/정지 (더블클릭 초기화). 계획 시간보다 3분 이상 늦으면 빨간색 |

클리커(프레젠터 리모컨)는 PageUp/PageDown을 보내므로 그대로 쓸 수 있습니다.

## 분량과 시간

- 총 95장: 실제 프레임 92장 + 지도·마무리용 화면 3장. 모든 장에 발표자 노트(말할 내용, 클릭할 곳, 학생 질문)가 있습니다.
- 1교시 42장 · 계획 48분 (S 압축 모드 약 45분)
- 2교시 53장 · 계획 49분 (S 압축 모드 약 43분)
- ‘보충’으로 표시된 장은 압축 모드에서 자동으로 건너뜁니다. 지도(O)에서는 언제든 클릭해 열 수 있습니다.

## 구성

- **1교시 (왼쪽 고리)**: 오프닝 → 어쩌다 엔지니어(강사 소개) → AI, 대체 뭐야?(개념 + 실습) → 생각하는 기계를 꿈꾼 70년(1943–2016)
- **2교시 (오른쪽 고리)**: ChatGPT는 어떻게 말할까 → 폭발(2017–2026) → 사람과 회사, 그리고 긴장 → 돈은 어디로 흐르나 → AI 시대의 일 → 마무리(제목 프레임 안으로 돌아옴)

|---|---|
